# data/

Local data. **None of these files go into the repository** (see `.gitignore`): the source of truth is
the project's Drive folder and the DB is always rebuildable.

- `raw/` - original datasets downloaded from Drive (CSV/Excel). File IDs in [../docs/DRIVE-MANIFEST.md](../docs/DRIVE-MANIFEST.md).
- `inbox/` - fallback for manual downloads when a domain is not whitelisted yet (see the `fetch` module).
- `cache/` - cache of raw network files (hash for updates).
- `euroleghe.db` - SQLite generated by `python -m euroleghe_ingest rebuild`. Idempotent, deletable.
